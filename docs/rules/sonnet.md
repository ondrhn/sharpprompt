# Claude Sonnet 5 and 5.5

## sonnet-literal-scope
Spell out how far an instruction reaches ("every file under src/, not just this one"). Sonnet 5 reads prompts literally and does not generalise an instruction from one item to the rest.
Source: [Prompting Claude Sonnet 5, More literal instruction following](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5#more-literal-instruction-following)

## sonnet-no-extras
When the user wants only the change itself, say not to add tests, docs or files that were not asked for. Sonnet 5.5 tends to add them.
Source: [Prompting Claude Sonnet 5.5, Steer initiative and scope](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5-5#steer-initiative-and-scope)
