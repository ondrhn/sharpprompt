# Claude Haiku 5.5

## haiku-run-a-check
For a code change that can be run, built or type-checked, ask for a real check (the tests, the type-checker, the build) before calling it done. Haiku 5.5 at low effort sometimes reports a change as done without checking it.
Source: [Prompting Claude Haiku 5.5, Tell coding agents to verify their changes](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-haiku-5-5#tell-coding-agents-to-verify-their-changes)
