# expenses

Turns a month of expense rows into the totals the monthly email job sends.

- `calc.py`: amounts and the month report
- `dates.py`: month keys and days per month
- `budget.py`: per-category totals and budget alerts
- `export.py`: CSV export of a report
- `cli.py`: `python3 cli.py rows.csv` prints the report

Run the tests with `python3 run_tests.py`.
